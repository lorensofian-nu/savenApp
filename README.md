# SAVEN - Joyería en Oro 18K ✨

> *"Más que oro, construimos confianza en nuestros clientes"*

Plataforma web de comercio y cotización de joyería fina en Oro 18K (Ley 750), desarrollada como proyecto formativo SENATIC en la I.E. Municipal María Concepción Loperena (Cúcuta, Colombia).

---

## 💎 Características Principales

1. **Pantalla 1 - Splash / Bienvenida:**
   - Monograma de identidad visual (S-V-E con diamante).
   - Barra de carga interactiva y transición fluida.

2. **Pantalla 2 - Autenticación (Login & Registro):**
   - Formularios para inicio de sesión y registro de usuarios.
   - Conmutador de visibilidad de contraseña.
   - Botón de acceso rápido de prueba para evaluación.

3. **Pantalla 3 - Hub Principal:**
   - Panel de bienvenida con perfil activo y rol.
   - Acceso dual a las opciones principales: **Comprar Joyas** o **Publicar Joyas**.

4. **Pantalla 4 - Catálogo y Compra:**
   - Catálogo interactivo de piezas en oro 18K (cadenas, anillos, pulseras, dijes).
   - Filtro por categorías y filtro rápido de favoritos.
   - Detalle de pieza con especificaciones de peso, pureza (Ley 750) y disponibilidad.
   - Carrito de compras con cálculo de subtotales y simulación de checkout.

5. **Pantalla 5 - Publicación y Personalización:**
   - Formulario para publicación y cotización de joyas personalizadas.
   - Selector interactivo de imágenes de muestra y carga de archivos locales.
   - Cálculo estimado de presupuestos.

6. **Herramientas de Evaluación:**
   - Barra superior con navegación directa entre las 5 pantallas del proyecto.
   - Alternador de vista móvil / vista completa de escritorio.
   - Modal interactivo con la Ficha Técnica del Proyecto SENA.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5 Semántico:** Estructura de la aplicación web y accesibilidad.
- **Tailwind CSS (CDN):** Framework de utilidades para estilos ágiles y responsivos.
- **CSS3 Personalizado (`styles.css`):** Sistema de diseño con gradientes de oro 18K, modo oscuro (obsidiana) y animaciones.
- **JavaScript Vanilla (`script.js`):** Lógica reactiva de negocio, gestión de estado local, carrito, favoritos y modales.
- **Font Awesome 6 & Google Fonts (Cinzel / Plus Jakarta Sans):** Iconografía y tipografía de lujo.

## 🚀 Cómo Ejecutar el Proyecto

1. Clona el repositorio:
   ```bash
   git clone https://github.com/lorensofian-nu/savenApp.git
   cd savenApp
   ```
2. Abre `index.html` en cualquier navegador web moderno (o utiliza una extensión como *Live Server* en VS Code).
